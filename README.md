# password-strength-checker

A beginner Python project that checks password strength using basic security rules

##Features
-Checks password length
-Checks for uppercase and lowercase letters
-Checks for numbers
-Checks for special characters
-Gives a basic password strength result

##How to run
Run the python file:
python password_checker.py

##Project Goal
This project helps beginners understand basic Python programming and password security concepts

1.Make sure Python is installed.
2.Download or clone this repository.
3.Open a terminal on the projcet folder.
4.Run:
